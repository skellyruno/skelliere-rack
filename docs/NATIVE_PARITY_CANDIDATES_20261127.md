# Native parity candidates — 2026-11-27

Base: `6e91cd065091a7dc9f621359902bacfb57827f81`. These are **portable integration candidates, not enabled rack modules**. No changes to production DSP, JUCE editor, automation, or state. No external engine sources or private audio are committed.

## Delay

`research/NativeDelayExchange.h` adapts the exact Skellay `72522005da84c9e6b53d8f3b7e218e4f2b903652` native Engine and EngineExchange interfaces. Structural preparation and retirement belong to a single control-thread producer; processing is on the audio thread. It provides a 20 ms crossfade, rejects invalid tempo or over-budget Bank configurations before constructing the engine, and does not substitute other algorithms. The per-engine limit is 128 MiB estimated delay storage, not a whole-rack RSS cap; it includes conservative Bank preparation transient storage but excludes miscellaneous engine memory. Several engines can coexist during switching; rack-wide budgeting and slot ownership remain mandatory. At tempos below the chosen reserve floor, callers must prepare a valid model rather than silently change the requested tempo. Old-tail preservation across model changes is not asserted.

12 direct comparisons (Classic, Modern, two-bank configuration; 44.1, 48, 96, 192 kHz) passed with exact output. 12 successive model publications: zero measured global C++ new/delete calls during callback processing. Two-bank native ring storage at 48 kHz: 6.23 MiB (24.91 MiB at 192 kHz). Eight banks, 4x, 192 kHz at a 30 BPM floor: rejected under the 128 MiB per-engine preparation limit; conservative estimated temporary delay storage 797 MiB. Native default Classic on a private ten-second vocal peaked +1.48 dBFS; Modern -0.09 dBFS; the two-bank wet-only fixture -24.26 dBFS. These settings are not loudness matched, and no sound-quality preference is inferred.

## Glitch

`research/NativeGlitchPattern.h` wraps exact SkellGlitch native headers from `9618e6f31689973809b03b897b6b50d595294b34`. Supports block-supplied pattern state, 1–32 steps, probability, swing, four reverse styles, seeded chaos, native trigger entry point and sidechain onset input, explicit wet output trim. It is full-band, zero-PDC candidate processing only. The caller must deliver stable block snapshots and sample-accurate MIDI/sidechain events; host trigger/UI routing, trigger-transition listening, complete state persistence and editor wiring remain unverified. It is not a substitute for the standalone plugin's complete processBlock. Four rates passed reverse-style, block partition, edited pattern, deterministic chaos, manual trigger and headroom tests. With the ten-second vocal at full wet, the gate peak moved +0.41 to -0.89 dBFS with the explicit -1.3 dB wet trim. No hidden limiter; input above full scale or other rack effects can still overload.

Both candidates passed optimized and ASan/UBSan portable builds. Reproduce with `SKELLIERE_NATIVE_SOURCE_ROOT=/owner/sources sh tests/run_native_parity_candidates.sh [mono_48000_f32le.raw]`. The script verifies every required Delay/Glitch source hash. Optional sanitizer flags: `CXXFLAGS='-O1 -g -fsanitize=address,undefined -fno-omit-frame-pointer'`. Source retrieval is owner-only. The offline JUCE kit passed 13 checksums and its dependency setup probe, but no new full JUCE editor build or Windows VST3 was performed for these candidates.
