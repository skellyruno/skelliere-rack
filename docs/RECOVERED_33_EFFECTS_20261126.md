# Skelliere Rack — 33-effect development candidate, 2026-11-26

Base: `6dc9ebacfa2486e680ce302b9b808b2d592ee75a`, draft PR #3. This candidate appends Demon (31), SSL Strip (32), Hush (33). Existing normalized host parameters and module IDs are preserved; MixHead and Dope DSP intentionally changed. MixHead reports 12 samples of latency; Demon reports its prepared latency, 1264 samples at 44.1 kHz. Processor sums selected serial latencies and aligns global bypass. This is a timing change from the old MixHead, not a bit-identical sound-preservation claim.

## Source provenance and scope
- VoiceShift and VocalPitch: recovered from user-supplied Skelly research/source archives (`SKELLY_R43_APPROVED_OVERTIME_DSP_PRIVATE.zip`, `skell dsp2.txt`, `VoiceShift.h`). The latter identifies AGPL-3.0; original notices and provenance preserved. User authorizes Skelly integration; no independent license determination. Standalone rack adapter replaces the original host/MIDI wrapper, uses scalar VocalPitch (SIMD helper absent), corrects corrupted `break` token, preserves original pitch/formant/drive/robot/quantize/link/mix laws and the measured stereo-lag behavior. MIDI note input is not exposed in this audio-effect rack.
- SSL: measured E/G console from the same user's R43 archive (`intake/ssl.cpp`, `VoiceMatch.h`, measured E/G tables and dynamics). Four fixed-frequency band gains, E/G switch and linked compression macro are exposed. The underlying source has additional options not exposed in the compact rack UI. No claim of exact vendor match.
- Dope: original Spectral4 from Skell VST decompiler PR #1, `experiments/engine_lab/Spectral4.h` blob `a118379e382aa2482c20d9bb6cda2055ea7a7c55`. Integrated two parallel profiles, linked dynamic high-band weights and smoothed mode blend; residual wet gain and dry gain are independent. Not exact Dopamine behavior.
- MixHead: original symmetric 49-tap 4x residual FIR, 12-sample phase-aligned dry path. Independent tape-color candidate, not recovered tape emulation.
- RubyQ: original three-band shelf/bell EQ with gain-dependent mid Q. Full VT-5 response/control mapping remains unavailable.
- Hush: original adaptive four-band downward noise attenuation, not a recovered NS1 engine.

## Evidence
- Verified offline JUCE 8.0.12 kit, local native actual JUCE editor: 37/37 full scenes, two new four-scene captures and motion pause/visibility regressions. First pass Hush and Demon revised and recaptured. Native editor used cached Release JUCE objects and low-optimization editor TUs to conserve memory, not a release-grade VST3 build.
- 16 baseline C++ programs passed, plus recovered module regression: 48 mono/stereo bypass impulse cases across 44.1/48/96/192 kHz; Demon +6 semitones 220 to 312 Hz; both SSL circuit HF controls effective; quiet synthetic noise reduced 27.19 dB at full suppression. ASan/UBSan on analog catalog and recovered-module regression passed. Native processor regression exercised host parameter ordering and state/undo/snapshot/slot behavior.
- MixHead max drive, 48 kHz, mono 0.35 amplitude: 7 kHz fundamental gain +1.771 to -5.380 dB, vs -4.933 to -5.376 dB at 1 kHz; 17 kHz folded third harmonic -31.442 to -63.223 dBc. The FIR intentionally attenuates nonlinear high-frequency residual, so this is not a broadband flatness claim.
- Real private approved Overtime vocal, 12 seconds, 44.1 kHz, stereo, 257-frame blocks: new MixHead 235 ns/stereo frame versus previous 173 ns (single run, O3 host-free wrapper; machine and load dependent). RMS change -0.476 dB vs -0.366 dB old; peak -6.35 vs -2.18 dBFS at 65% drive. All six candidates finite. Input is a previously processed vocal; no vendor-reference render or subjective preference established. RMS-matched private audition separated from code; do not publish recordings.
- Windows VST3, pluginval and FL Studio are not verified by this local work. Preserve draft PR. No claim of final VT-5, exact SSL full control coverage, NS1 parity, or release readiness.
