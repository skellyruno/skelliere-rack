# Premium analog rack / Necromancer hero-dial integration

The original Reanimate dial uses `Assets/dial_well.png` (blob 42fe571e01e35d4b7232041eb22184f541e9cbd4) and `Assets/knob_cap_big.png` (blob 3906e520d102b83751e08061c5fc0115187a27d8) from skellyruno/skell-necromancer-vst. The previous rack renderer placed the cap over a bright machined disc, which washed out the cutout mark; it also left the cap stationary and used a generic pointer. The new renderer uses the actual well, dark backing, original cap rotation formula and an external radial indicator. Ring geometry and cap scale are adapted for dense rack controls; the animated rune field is not copied. The original artwork remains byte-identical. No generated mockup is used.

The existing 1260 x 790 logical editor, zoom options and four/five-slot modes remain. New metal gradients, panel bevels, typography, meter bezels, LED segments, preset and footer treatments are UI-only. All genuine Bell 73 and Jet controls and meter semantics are retained (the concept depicts a different EQ/compressor). The real editor harness now asserts original artwork availability; existing 29 scenes cover scaling, bypass, catalog, navigation and library modes. Actual screenshot inspection and Windows verification are required on the exact commit before merge.
