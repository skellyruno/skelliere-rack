## Cap-only correction after actual d4bcd80 review
The real editor capture showed a bulky black well and undersized silver face. The owner explicitly requested only the original main metal knob, without the surrounding black circle. The next renderer therefore directly ports the original ReanimateDial cap draw/rotation, enlarges the face to roughly 81% of the slider size, removes the dial well from the compiled UI, and limits backing to the alpha cutouts and narrow physical sidewall. The original dial_well.png remains in repository history/assets but is not compiled or drawn. Scale ticks are painted on the module faceplate. The original PNG is not retouched. All effect controls, parameter bindings and layout dimensions remain unchanged. Actual source build and capture review required.
