Not a factory replacement or listening-approved release. UI and DSP algorithms unchanged.

Copy the XML into the Windows user application data directory, SkellAudio/SkellierRack/DreamStrips. Reopen Rack and load Studio Lead from Dream Strips; set input/output to 0 dB and bypass off.

The eight-slot chain (Hush, SSL Strip, Fast C, Program Opto, MixHead, Air, De-Esser, Brick 1) was rendered from three private dry recordings using the actual native JUCE processor built from 30428f6eae1ef6d7f8e7a4a06fde72ed47113234. Native versus optimized module output maximum absolute difference below 5e-35; one take rendered sample-identically with 257 and 512 sample blocks. Two recordings were held out for the final fixed preset validation. No pitch correction or spatial effects in this candidate. The listening copy used static integrated loudness matching near -18 LUFS. No subjective preference, DAW compatibility, or vendor sound parity is claimed.
